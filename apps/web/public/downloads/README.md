# Downloads

The TrendLIX Scan Helper, offered by the scan window (Scan, next to the document uploads) when it isn't running on the
computer:

- `TrendLIX-Scan-Helper-mac.zip`
- `TrendLIX-Scan-Helper-windows.zip`

They are made by the build in `tools/scan-helper` and copied here; the links are in
`apps/web/src/lib/scan-helper.ts` (`SCAN_HELPER_DOWNLOADS`). Keep these names, or change them there too.
